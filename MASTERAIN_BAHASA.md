# Spesifikasi Bahasa Pemrograman MASTERAIN

MASTERAIN adalah bahasa pemrograman tingkat tinggi yang dirancang untuk kedaulatan nalar digital. Bahasa ini menggunakan metafora arsitektur semesta dan kearifan lokal Nusantara.

## Prinsip Dasar
- **Kedaulatan**: Setiap kode adalah titah yang berdaulat.
- **Keselarasan**: Struktur kode harus selaras dengan logika alam.
- **Manifestasi**: Program adalah manifestasi dari niat pengembang.

## Aturan Sintaksis
- File diakhiri dengan ekstensi `.masterain`.
- Komentar menggunakan `##` untuk satu baris, dan `###` untuk blok.
- Definisi blok menggunakan `mulai` dan `akhir`.

## Tipe Data
- `angka`: Bilangan bulat atau desimal.
- `teks`: Rangkaian karakter.
- `logika`: `nyata` atau `maya`.
- `hampa`: Kosong.

## Struktur Kendali
### Keputusan
```masterain
jika (kondisi) mulai
    # titah
akhir jika
sebaliknya mulai
    # titah
akhir sebaliknya
```

### Perulangan
```masterain
selama (kondisi) mulai
    # titah
akhir selama
```

## Arsitektur (Kelas/Trah)
```masterain
arsitektur NamaArsitektur mulai
    pondasi (param) mulai
        # konstruktor
    akhir pondasi

    aksi namaAksi() mulai
        # metode
    akhir aksi
akhir arsitektur
```

## Operasi Asinkron (Arus)
- `alir`: Menjalankan fungsi secara asinkron.
- `tunggu`: Menunggu hasil aliran.

## Kecerdasan (Sanubari)
- `sanubari`: Mendefinisikan model kecerdasan buatan terintegrasi.
